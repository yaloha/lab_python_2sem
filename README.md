# Лабораторная №3. Очередь задач: итераторы и генераторы

## Ключевые отличия от 2 лабораторной:
В проект добавлена умная коллекция TaskQueue, которая объединяет источники данных (из ЛР1) и валидируемые модели (из ЛР2)
- Реализован магический метод `__iter__` с использованием ключевого слова `yield`.
- Очередь является многократно итерируемой: каждый вызов iter(queue) создает новый генератор.
- Реализован метод `__len__`, позволяющий мгновенно получать количество задач в очереди через стандартную функцию `len()`
- Созданы методы фильтрации (`filter_by_priority`, `filter_by_status`), реализованы как генераторы.
- Фильтрация не происходит в момент вызова метода — она выполняется «на лету» только тогда, когда данные реально запрашиваются (например, при выводе в API). Это экономит память при работе с большими объемами данных.
- Добавлены эндпоинты для визуализации работы фильтров. (Метод загрузки данных в очередь `load_from_source` сделан асинхронным для корректной работы с fastAPI)
## Установка и запуск
1. **Инициализируйте venv, установите зависимости:**
   ```uv sync```
2. **Запустите проект**:
   - Приложение состоит из основного сервера и mock-сервера для API.
   - Запуск Mock-API (порт 8001): ```uv run python -m src.ext_backend```
   - Запуск основного сервера (порт 8000): ```uv run python -m src.main ```
3. **Запуск тестов**:
   - Запуск тестов: `pytest`
   - Запуск тестов с отчетом о покрытии: `pytest --cov=src`
