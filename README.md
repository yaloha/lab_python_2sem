# Лабораторная №4. Очередь задач: итераторы и генераторы

## Отчет по курсовой работе
Находится в корне, файл `Курсовая работа по ПнЯP, Чеботарь Иван Сергеевич, .docx`
## Ключевые отличия от 2 лабораторной:
В проект добавлена полноценная подсистема асинхронного выполнения задач (AsyncExecutor)
- Контракт обработчиков через `Protocol`: Описан строгий протокол `TaskHandler` с использованием `typing.Protocol` и `@runtime_checkable`. Любой кастомный класс, реализующий асинхронный метод `handle(task)`, автоматически встраивается в систему
- Метод `register_handler` в исполнителе проверяет соответствие протоколу «на лету» с помощью `isinstance()`. При попытке зарегистрировать некорректный объект приложение выбрасывает `TypeError`.
- Внутри исполнителя используется `asyncio.Queue`. Веб-эндпоинт выступает в роли поставщика задач, а фоновые воркеры конкурентно разбирают её.
- Исполнитель поддерживает запуск настраиваемого количества фоновых процессов через `asyncio.create_task()`
- Реализован асинхронный контекстный менеджер `TaskExecutionContext (__aenter__ / __aexit__)`. Он регулирует смены статусов `(IN_PROGRESS -> DONE)` и замеряет  время выполнения задачи с помощью `time.monotonic()`.
- Контекстный менеджер изолирует выполнение каждого хэндлера. Если происходит сбой, `__aexit__` перехватывает исключение, логирует ошибку, возвращает статус задачи к `CREATED` для последующих попыток и гасит ошибку (`return True`). Один упавший хэндлер не останавливает работу всей системы.
- В `main.py` добавлен POST-эндпоинт `/tasks/execute`, который динамически запрашивает задачи из случайного источника (ЛР1), валидирует их дескрипторами (ЛР2), загружает в очередь (ЛР3) и запускает параллельный пул воркеров для их обработки.
## Установка и запуск
1. **Инициализируйте venv, установите зависимости:**
   ```uv sync```
2. **Запустите проект**:
   - Приложение состоит из основного сервера и mock-сервера для API.
   - Запуск Mock-API (порт 8001): ```uv run python -m src.ext_backend```
   - Запуск основного сервера (порт 8000): ```uv run python -m src.main ```
3. **Запуск тестов**:
   - Запуск тестов: `pytest`
   - Запуск тестов с отчетом о покрытии: `pytest --cov=src`
