# Лабараторная работа №1. Источники задач и контракты.

Данное приложение представляет собой модуль приема задач из различных источников. Используется объектная модели Python, механизмы Duck Typing и Runtime-проверка контрактов с использованием `typing.Protocol`.

### Реализованные источники:
1. **APISource**: Получает задачи из внешнего HTTP API (реализован mock-сервер).
2. **FileSource**: Считывает задачи из локального JSON-файла.
3. **GeneratorSource**: Генерирует случайные задачи

## Установка и запуск
1. **Инициализируйте venv, установите зависимости:**
   ```uv sync```
2. **Запустите проект**:
   - Приложение состоит из основного сервера и mock-сервера для API.
   - Запуск Mock-API (порт 8001): ```uv run src/ext_backend.py```
   - Запуск основного сервера (порт 8000): ```uv run src/main.py```
3. **Запуск тестов**:
   - Запуск тестов: `pytest`
   - Запуск тестов с отчетом о покрытии: `pytest --cov=src`
